after talking to chatgpt about it.

In bios:

  • 4g decoding should be ON
  • fastboot OFF
  • CSM off

but MOST IMPORTANT - if IOMMU group shows as 0000.03.0 etc it is stuffed!

MUST be IOMMU group pci@0000.01.xx.x

at which point it works, lspci does not hang etc.

still do not understand why it changes, but a reboot seems to fix it.

lspci -t

find /sys/kernel/iommu_groups/ -type l | sort

for g in /sys/kernel/iommu_groups/; do echo "IOMMU Group ${g##/}:" for d in $g/devices/; do lspci -nns ${d##/} done echo done

ChatGpt says all NVIDIA devices MUST be vfio-pci and turn off PCI ASPM in bios.

GPU passthough

so it appears that in order to be stable:

BIOS is finicky and must be

  • 4g decoding should be ON
  • fastboot OFF
  • CSM off
  • PCI apsm should be off
  • PEG should be GEN3

GRUB should be configured

  • include the vcio ids to try and load those drivers early

Initramfs changes

  • i added some modules here as per docs, no idea if it helps

At boot time

  • GPU must be in IOMMU group 0000.01.xx.x
  • only vcio drivers in effect for the four items in the group
